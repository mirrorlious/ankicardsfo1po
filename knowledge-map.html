        • 无行为能力（<8周岁 / 不能辨认）
      • 监护
        • 未成年人监护（父母·祖辈·协议·指定·机关）
        • 成年人监护（意定监护·法定监护）
        • 监护人职责与撤销
      • 宣告失踪
        • 条件（下落不明满2年）
        • 财产代管人
      • 宣告死亡
        • 条件（普通4年 / 意外2年 / 意外且无生还可能即时）
        • 法律后果（婚姻消灭·财产继承）
        • 死亡宣告撤销
      • 个体工商户和农村承包经营户

        • 非营利法人（事业单位·社会团体·捐助法人）

        • 责任能力
      • 法人机关

        • 合并（吸收合并·新设合并）
      • 终止与清算
        • 终止事由（解散·破产·撤销）
        • 清算程序与责任
    • 第五章 非法人组织

        • 个人独资企业
        • 合伙企业
        • 不具有法人资格的专业服务机构
    • 第六章 民事法律行为
      • 概念与特征
      • 分类
        • 单方·双方·多方
        • 要式·不要式
        • 有偿·无偿
        • 主行为·从行为
      • 意思表示

        • 明示·默示·沉默
        • 解释规则

        • 成立要件（一般·特别）
        • 生效要件（行为能力·意思真实·不违法）
      • 效力体系
        • 无效（违反强行法·违背公序良俗·虚假意思表示）
        • 可撤销（重大误解·欺诈·胁迫·显失公平）
        • 效力待定（限制行为能力人·无权代理·无权处分）
      • 附条件与附期限
        • 附条件（延缓条件·解除条件）
        • 附期限（始期·终期）
    • 第七章 代理
      • 概念与特征
      • 分类
        • 委托代理 / 法定代理
        • 直接代理 / 间接代理
        • 本代理 / 复代理
      • 代理权
        • 取得（授权行为）
        • 行使规则（权限范围·转委托）
        • 消灭（事务完成·撤销·代理人丧失能力）
      • 无权代理
        • 狭义无权代理（效力待定·被代理人追认权·相对人催告权与撤销权）
        • 表见代理（构成要件·法律后果：有效）
    • 第八章 诉讼时效
      • 概念与特征（胜诉权消灭·实体权利不消灭）
      • 适用范围
        • 适用：请求权（债权·物上请求权等）
        • 不适用：物权请求权·人格权·抚养费等
      • 期间
        • 普通时效：3年（自知道或应当知道权利受损及义务人之日起）
        • 最长时效：20年（自权利被侵害之日起）
      • 中止·中断·延长
        • 中止（最后6个月内因法定障碍暂停·障碍消除后继续6个月）
        • 中断（请求·同意·起诉·仲裁→重新起算）
        • 延长（法院裁量·20年特殊情况）
      • 届满后果
        • 义务人获得抗辩权
        • 自愿履行不得主张返还

      • 所有权取得的特别规定

        • 拾得遗失物（返还义务·悬赏·公告1年归国家）
        • 发现埋藏物（参照拾得遗失物）

        • 发生原因（合同·侵权·无因管理·不当得利·单方允诺）
      • 合同概述
        • 概念与特征（合意·双务/单务·有偿/无偿）
        • 调整范围（平等主体间民事权利义务关系）
        • 分类（有名/无名·要式/不要式·主/从合同）
        • 合同解释（文义·整体·目的·习惯·诚信）
      • 合同订立
        • 要约（具体确定·受其约束·到达生效·撤回与撤销）
        • 承诺（同意要约·通知/行为方式·到达生效·迟延与迟发）
        • 成立要件（当事人·合意·标的确定·可能）
        • 预约合同（约定将来订立本约）
        • 格式条款（提示说明义务·无效情形·不利解释规则）
        • 缔约过失责任（恶意磋商·隐瞒·虚假·泄露秘密）
      • 合同效力
        • 生效要件（行为能力·意思真实·不违法）
        • 效力待定（限制行为能力人·无权代理·无权处分）
        • 无效（违反强行法·违背公序良俗·虚假意思表示）
        • 可撤销（重大误解·欺诈·胁迫·显失公平）
      • 合同履行
        • 履行规则（全面适当履行·约定不明时的补充）
        • 同时履行抗辩权（双务合同·未约定先后）
        • 先履行抗辩权（有先后顺序·先履行方未履行）
        • 不安抗辩权（先履行方·对方经营恶化·中止履行）
      • 债的保全
        • 代位权（怠于行使到期债权·影响债权人·直接受偿）
        • 撤销权（无偿处分·不合理低价·1年/5年除斥期间）
      • 合同变更与转让
        • 债权让与（通知债务人·非经同意对债务人不生效）
        • 债务承担（债权人同意）
        • 概括转移（合同权利义务一并转让）
      • 合同终止
        • 清偿（履行完毕）
        • 抵销（法定抵销·约定抵销）
        • 提存（债权人无正当理由拒绝受领·下落不明等）
        • 免除（债权人放弃债权）
        • 混同（债权债务同归一人）
        • 解除（约定解除·法定解除·协议解除）
      • 违约责任
        • 归责原则（严格责任为主·过错责任为辅）
        • 构成要件（违约行为·无免责事由）
        • 承担方式（继续履行·采取补救·赔偿损失·违约金·定金）
        • 免责事由（不可抗力·约定免责）
        • 减损规则·可预见规则·与有过失
    • 典型合同
      • 保证合同
        • 一般保证（先诉抗辩权）
        • 连带责任保证（无先诉抗辩权）
        • 保证期间与诉讼时效
      • 买卖合同
        • 标的物交付与所有权转移

  • 第六编 侵权责任
    • 侵权责任通则
      • 归责原则
        • 过错责任原则（一般侵权·举证责任在受害人）
        • 过错推定责任（法律明确规定时·举证责任倒置）

        • 主观过错（故意·过失）
      • 抗辩事由
        • 受害人过错（减轻或免除责任）
        • 第三人原因（由第三人承担·法律另有规定除外）
        • 不可抗力（全部免除·法律另有规定除外）
        • 正当防卫（适当限度内免除·超过必要限度适当承担）
        • 紧急避险（由引起险情者承担·自然原因可适当补偿）

      • 损害赔偿
        • 人身损害赔偿
          • 医疗费·护理费·交通费·营养费·住院伙食补助费
          • 误工费·残疾赔偿金·死亡赔偿金·被扶养人生活费
          • 丧葬费
        • 财产损害赔偿（恢复原状·折价赔偿·实际损失）
        • 精神损害赔偿（造成严重精神损害·自然人专属）
        • 惩罚性赔偿（产品缺陷·环境污染·知识产权侵权等）
    • 特殊侵权责任
      • 产品责任
        • 归责原则：无过错责任
        • 责任主体：生产者·销售者（不真正连带）
        • 惩罚性赔偿（明知缺陷·造成死亡或健康严重损害）
      • 机动车交通事故责任
        • 归责原则：过错责任（机动车间）/ 过错推定（机动车对非机动车行人）
        • 保险优先（交强险·商业三者险）
        • 租赁/借用：使用人承担责任·所有人有过错时承担相应责任
      • 医疗损害责任
        • 归责原则：过错责任（一般）/ 过错推定（特定情形）
        • 免责事由（患者不配合·紧急抢救·当时医疗水平难以诊疗）
        • 隐私与个人信息保护
      • 环境污染和生态破坏责任
        • 归责原则：无过错责任
        • 因果关系举证责任倒置
        • 惩罚性赔偿·生态修复责任
      • 高度危险责任
        • 归责原则：无过错责任
        • 类型：高空·高压·地下挖掘·使用易燃易爆放射性物品
        • 限额赔偿（部分情形）
      • 饲养动物损害责任
        • 归责原则：无过错责任（一般）/ 更严格责任（禁止饲养的烈性犬）
        • 抗辩：受害人故意（可减轻·禁止饲养的动物除外）
        • 动物园：过错推定
      • 建筑物及物件损害责任
        • 高空抛物：可能加害人补偿·物业安全保障义务
        • 建筑物倒塌：建设单位与施工单位连带（过错追偿）
        • 搁置物·悬挂物脱落：过错推定（所有人·管理人·使用人）
